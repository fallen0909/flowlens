# FlowLens Privacy Policy

Last updated: 2026-07-09

FlowLens is a browser extension that organizes images and videos from the current webpage into a fullscreen gallery viewer.

## Data Collection

FlowLens does not sell, share, or upload browsing history, image contents, video contents, cookies, account credentials, or personal information to a FlowLens server.

The extension processes webpage media URLs locally in the browser so it can display galleries, preview media, and start downloads requested by the user.

## Data Storage

FlowLens stores extension preferences such as theme, column count, autoplay speed, video preview setting, and launch button position using browser extension storage. When browser sync is enabled, these preferences may sync through the browser vendor account sync service.

Page bookmarks and viewing preferences may be stored locally in the browser on the user's device.

## Network Access

FlowLens may request media files from the webpage the user is viewing, including image or video URLs already present on that page, in order to preview or download them. These requests are made directly by the browser or extension runtime.

## Downloads

When the user chooses to download media, FlowLens uses the browser downloads API to save selected files to the user's device.

## Contact

For support or privacy questions, use the support contact configured in the Microsoft Edge Add-ons listing.
