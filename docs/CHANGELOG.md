# 变更日志

## 1.10.0 - 2026-07-14

- 修复大图右上角播放按钮被旧控制器抢占、点击后无法自动切换图片的问题，统一由单一幻灯片控制器管理。
- 优化大量图片的分帧渲染、索引同步和瀑布流列高计算，减少加载过程中反复全量布局造成的滚动卡顿。
- 浏览器扩展改为轻量入口按需加载功能模块，站点专用适配仅在对应域名注入。
- 扩展设置和页面收藏改用 `chrome.storage`，避免网页 `localStorage` 污染全局设置或造成跨站数据不一致。
- 移除全局隐藏浏览器下载界面的权限和行为，并为后台跨域请求增加协议、类型、大小和超时校验。
- 补全扩展源码同步和发布检查，避免正式源码与扩展目录再次漂移。

## 1.9.9 - 2026-07-08

- 修复 1.9.8 中会话恢复仍可能在用户手动滚动后执行的问题，避免下拉后被拉回顶部。
- 用户滚轮、触摸、拖动滚动条或键盘滚动时，会取消本次位置恢复。
- 恢复定位改为即时定位，不再受平滑滚动动画影响。

## 1.9.8 - 2026-07-05

- 新增站点适配中心，设置面板可查看当前站点、命中的适配器、采集策略、分页进度、组图队列和渲染队列。
- 强化会话恢复，保存并恢复筛选、大图位置、当前媒体 URL 和瀑布流滚动位置。
- 优化大量图片页面的流畅度，瀑布流改为分帧批量渲染，卡片启用局部布局隔离、异步解码和触摸惯性滚动。
- 修复 README、安装页、扩展 manifest 和版本中心的版本一致性，并让发布校验覆盖这些文件。

## 1.7.34 - 2026-07-03

- 修复 1.7.33 中播放补丁加载过晚的问题，播放按钮事件现在会在原大图增强补丁之前接管，点击后可真正开始自动切换。
- 保留 1.7.33 的大图 1:1 滚轮缩放和组图队列补齐逻辑。
- 同步更新电脑端、手机端入口脚本、版本中心、README 和 `version.json`。

## 1.7.33 - 2026-07-03

- 修复大图模式右上角自动播放按钮失效、误触发退出大图模式的问题，点击播放按钮会优先拦截并独立切换自动播放状态。
- 新增大图 1:1 模式下滚轮缩放：滚轮向上放大、向下缩小，并尽量保持当前视野中心。
- 修复部分短视频列表页进入组图后上一组/下一组不可用的问题，补齐从列表页、当前页和会话缓存识别组图队列的逻辑。
- 同步更新电脑端、手机端入口脚本、版本中心、README 和 `version.json`。

## 1.7.22 - 2026-06-26

- 新增 xchina 图库广告素材预过滤补丁，针对已确认广告图文件名在核心采集前先移除对应节点，避免已被页面屏蔽的广告再次进入图片流。
- 将 xchina 广告过滤补丁加载顺序放在核心采集脚本之前，电脑端和手机端同步生效。
- 同步更新电脑端、手机端入口脚本、版本中心、安装页和 `version.json`。

## 1.7.21 - 2026-06-26

- 新增稳定悬浮工具栏，播放、收藏、关闭按钮不再跟随大图内容重建，解决切图时播放图标闪烁的问题。
- 收窄播放按钮事件保护逻辑，只拦截播放按钮被大图层误识别为空白点击的问题，不再影响收藏、关闭和箭头按钮的原生逻辑。
- 同步更新电脑端、手机端入口脚本、版本中心、安装页和 `version.json`。

## 1.7.20 - 2026-06-26

- 修复大图播放按钮误触发的问题，播放、收藏、关闭、箭头等控件点击不再被大图层当成空白点击处理。
- 图片切换取消淡入淡出，改为图库式横向跟手滑动：当前图滑走的同时相邻图跟进。
- 保留高清图后台预解码能力，但替换时不再做渐隐渐显，减少视觉跳变。
- 同步更新电脑端、手机端入口脚本、版本中心、安装页和 `version.json`。

## 1.7.19 - 2026-06-26

- 新增大图 iOS 风格顺滑补丁，接管 lightbox 图片 `src` 替换，先后台预解码高清图，再平滑替换，减少缩略图切高清图时的闪烁和跳动。
- 强化大图媒体层过渡效果，覆盖稳定补丁中过度禁用动画的问题，恢复淡入、轻微缩放和 GPU 合成优化。
- 点击瀑布流卡片前预热当前图及相邻图片，提升首次打开和连续切换时的响应速度。
- 同步更新电脑端、手机端入口脚本、版本中心和 `version.json`。
